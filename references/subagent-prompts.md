# Шаблоны промптов субагентов (Фазы 3–4)

Язык отчёта субагента — язык владельца репозитория: он виден по репликам USER MESSAGES
в дайджестах. Если реплики смешанные — бери язык большинства. В шаблонах ниже это уже
вшито в формулировку; не заменяй её на жёстко заданный язык.

## Фаза 3: аналитик поведения агентов

> Ты аналитик поведения ИИ-агентов. ТОЛЬКО ЧТЕНИЕ И АНАЛИЗ, ничего не модифицируй.
> Прочитай файлы-дайджесты сессий <инструмент/эпоха> над репозиторием <REPO>: <список путей>.
> Формат дайджеста: метаданные, USER MESSAGES (полные тексты пользователя в хронологии),
> ASSISTANT TEXTS (начала ответов), TOOL CALLS (последовательность; E=ошибка с куском вывода).
> Верни структурированный отчёт НА ЯЗЫКЕ РЕПЛИК ПОЛЬЗОВАТЕЛЯ из этих дайджестов:
> 1) Обзор — что делалось; 2) Затыки и циклы агента — [сессия, timestamp] что делал →
> что не получалось → как выбрался, с цитатами; 3) Вмешательства пользователя —
> прерывания/поправки/недовольство, короткие цитаты; 4) Ошибки инструментов и среды —
> кластеры и обходные приёмы; 5) Ловил/пропускал — где агент сам находил свои ошибки
> до пользователя, где ошибка доезжала до пользователя; 6) Стиль взаимодействия;
> 7) Топ-5 повторяющихся проблем периода. Каждый вывод — с цитатой/фактом из файла.
> Не выдумывай; мало данных — так и напиши.

Группировка: 4–7 дайджестов на субагента, по эпохам/инструментам. Для границ эпох
используй `data/digest_index.json` (t_start, число сообщений, ошибок, размер).

## Фаза 4: ground truth по escaped defects

> Ты аналитик качества процессов разработки с ИИ-агентами. ТОЛЬКО ЧТЕНИЕ. Источники:
> <список файлов валидации>, `git log`. Язык отчёта — язык сообщений владельца в этих
> источниках. Реестр дефектов, найденных людьми, в таблице: № / волна / описание / класс /
> серьёзность / повторялся ли. Таксономия по классам со счётчиками. Повторные побеги.
> Слепые зоны процесса — почему каждый класс не ловился. Что агенты ловили сами (из
> ревью-секций коммитов и отчётов). Топ-5 слепых зон с рекомендацией, какой проверкой
> каждую закрыть.

## Среда без субагентов

Если параллельные субагенты недоступны (например, чат без инструментария) — выполняй
роли последовательно сам: читай дайджесты группами по 4–7 файлов и отвечай на те же
вопросы шаблона, затем роль Фазы 4 по тем же источникам. Методика не меняется —
меняется время и глубина выборки (бери меньше групп, но не пропускай вопросы).
